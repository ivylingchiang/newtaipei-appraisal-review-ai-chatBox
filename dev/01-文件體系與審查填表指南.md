### 1.1 兩組文件的對應關係（重要）

文件刻意提供了**兩組平行的樣本**：

```
【已填範例組】金山區商業用地          【待作答組】樹林區普通住宅用地
  查估書表範本.pdf  ←對應→  評價基準明細表範例.pdf
        ↕ 同構                              ↕ 同構
  題目.pdf         ←對應→  評價基準明細表.pdf
```

**用法**：用金山組學會「怎麼填、怎麼算」，再套到樹林組作答。
**但兩組的級距門檻與修正率完全不同** —— 例如：

| 項目 | 金山商業用地 | 樹林普通住宅用地 |
|---|---|---|
| 建蔽率「優」 | 60% 以上 | **80% 以上** |
| 容積率「優」 | 240% 以上 | **460% 以上** |
| 主要道路寬度「優」 | 30m 以上 | **28m 以上** |
| 有無禁止建築 修正率 | ±40 | **±50** |
| 面積「優」 | 93㎡ 以上 | **600㎡ 以上** |

> ⚠️ **這是本題最大的陷阱**。命題文件明言「各案件之基準明細表內容可能因個案特性調整」。
> 系統**絕不可寫死級距**，必須以「案件所屬行政區 + 用地別」動態載入對應的基準明細表。

### 3.1 三張核心表的職責分工

| | 表3 地價區段勘查表 | 表5 區域因素分析明細表 | 表4 比較法調查估價表 |
|---|---|---|---|
| **單位** | 一個地價區段一份 | 一個案號一份（橫向排比準地+最多3個比較標的） | 一個案號一份 |
| **內容** | 現場勘查的**原始事實**（距離、寬度、有無設施） | 把事實轉成**優劣等級 + 修正百分比** | **個別因素**差異率 + 價格試算 |
| **比較層級** | 無比較，純記錄 | **區段 vs 區段**（區域因素） | **宗地 vs 宗地**（個別因素） |
| **輸出** | 各細項優劣等級 | 影響地價區域因素總修正數（%） | 比準地比較價格（元/㎡） |

> **關鍵分工**：區域因素（表5）處理「不同地價區段之間」的差異；個別因素（表4）處理「同區段內不同宗地」的差異。
> 手冊六(九)：若某因素已完全於區域因素反應調整，則不需再於個別因素重複調整（**避免重複修正**）。

## 4. 各文件內容細則

### 4.1 表3 地價區段勘查表

**眉欄**
- 年期：7 碼估價基準日（例 `1110901` = 民國111年9月1日）
- 區段編號：`P` + 母號3碼 + 支號2碼（例 `P002-00`）
- 區段範圍：四至描述（街路名、明顯建物）；公共設施保留地須填毗鄰非保留地區段號

**十一大類勘查項目**
1. 土地使用管制：都市計畫內外、使用分區、建蔽率、容積率、有無禁止建築、有無限制建築
2. 交通運輸：主要道路（名稱+寬度）、區段內道路平均寬度、大型車站（高鐵/火車/客運/捷運）、站牌（名稱+密集程度）、交流道、接近聚落/運銷中心/消費市場程度、區段內道路規劃及闢建程度
3. 自然條件：日照、景觀、傾斜度、保（排）水、地勢、風勢、土質
4. 土地改良：建築基地改良（整平填挖/開挖水溝/水土保持/鋪築道路/埋設管道/修築駁嵌）、農地改良
5. 公共建設：學校（國小/國中/高中/大專）、市場（傳統/超級/超大型）、公園廣場徒步區、觀光遊憩設施、停車場地、接近服務性設施
6. 特殊設施：電業（變電所/高壓鐵塔）、燃料（瓦斯槽/儲油槽）、殯葬（墓地/殯儀館/火葬場/納骨塔）、廢棄物（污水處理場/垃圾場/焚化爐）
7. 環境污染：水/噪音/廢氣/廢棄物/其他污染
8. 工商活動：百貨公司、金融機構、娛樂設施、大型展示中心或觀光飯店、顧客通行量、店鋪毗連狀態
9. 其他影響因素
10. 房屋建築現況：建築密度、建築型態
11. 土地利用現況：商業用/住宅用/工業用/住商混合/住工混合/農作用/漁牧用/空地/公共設施

**設施類的登載格式**（極重要，是距離判定的資料來源）
```
名稱：金山變電所    ○本區段內  ●本區段外(距 700 M)
```
→ 勾「本區段內」= 距離 0；勾「本區段外」則讀取 M 值。

**⭐ 優劣等級編碼**：範本表3 每個細項左側有兩個數字，格式為 `[第N級] [共M級]`
```
1  2  都市計畫(內外)      → 第1級/共2級 = 優
1  5  使用分區            → 第1級/共5級 = 優
3  5  主要道路   18M      → 第3級/共5級 = 普通
5  5  交流道     無       → 第5級/共5級 = 劣
2  5  保（排）水          → 第2級/共5級 = 稍優
```

### 4.2 評價基準明細表（判定依據）

每個細項是一張**方陣查表**，結構如下（以樹林住宅「容積率」為例）：

```
         基準區段
目標區段     優      稍優     普通     稍劣      劣          備註（級距定義）
  優        0     +6.25   +12.50  +18.75    +25       優：   460%以上
  稍優    -6.25     0     +6.25   +12.50  +18.75      稍優： 360%以上未滿460%
  普通    -12.5   -6.25      0    +6.25   +12.50      普通： 260%以上未滿360%
  稍劣   -18.75   -12.5   -6.25      0    +6.25       稍劣： 180%以上未滿260%
  劣       -25   -18.75   -12.5   -6.25      0        劣：   未滿180%
```

**三個結構性特徵**
1. **反對稱**：`M[i][j] = -M[j][i]`，對角線恆為 0。
2. **等差**：相鄰級距差固定 = 該細項最大修正率 ÷ (級數-1)。容積率最大 ±25，5級 → 步長 6.25。
3. **備註欄是級距定義**，也是「事實 → 等級」的唯一判定規則。

> **實作建議**：查表可簡化為 `修正率 = (比較標的等級序號 − 比準地等級序號) × 步長`。
> 例：比準地普通(3)、比較標的劣(5) → (5−3) × 6.25 = **+12.50**。與矩陣查表結果一致。

### 4.4 表4 比較法調查估價表

**用途**：估計**比準地之比較價格**。

**列結構（由上而下即為計算順序）**
```
0 基本資料               ← 表7 宗地個別因素清冊 / 地籍資料
土地正常單價              ← 表1-1 買賣實例調查估價表
交易日期 + 調整百分率      ← 地價指數/房價指數/物價指數
調整至估價基準日單價(元/㎡) = 土地正常單價 × (1 + 交易日期調整百分率)
地價區段號 + 區域因素調整百分率 ← 表5 之「影響地價區域因素總修正數」
個別因素調整 7~25 共 19 項差異率  ← 個別因素評價基準明細表
  1 宗地條件：7面積 8寬度 9深度 10形狀 11臨街情形 12地勢
  2 道路條件：13道路種類 14面前道路寬度
  3 接近條件：15學校 16市場 17公園廣場 18車站 19商圈
  4 周邊環境：20嫌惡設施 21停車方便性
  5 行政條件：22使用分區 23建蔽率 24容積率 25有無禁限建
  6 其他
合計 = Σ 個別因素差異率
調整百分率絕對值加總  → 價格形成因素之相近程度
試算價格 = 調整至估價基準日單價 × (1 + 區域因素% + 個別因素合計%)
比較標的權重
比準地比較價格 = Σ(試算價格 × 權重)
```

**填表細則**
- **免修正 vs 修正為0**：免修正項目的**條件欄與差異率一律填「-」**；應修正但無差異者填 `0`。兩者必須區分（手冊 六(七)2）。判斷為免比較項目須於全案備註欄加註理由。
- **接近條件與嫌惡設施**：比較標的原則填**與比準地相同之標的**；不同行政區案例，須有同等級影響力設施才填載，否則填「無」（手冊 六(六)2(2)）。
- **行政條件**按**交易當時**之土地使用管制規定填載。
- **容積率指法定容積率**；需就現況容積率修正者於「其他」欄處理並於備註欄通案說明。若實例已符合當地主要建築型態，則無須容積率修正（須於表1-1 敘明）。
- 比較標的以 3 件為原則；徵收範圍已影響市場時得選 1~3 件（查估辦法第17條第3項、第19條第2項可放寬蒐集期間與範圍，並須於備註欄敘明法條依據）。

**權重決定規則**（手冊 六(十一)，引不動產估價技術規則第27條）
以「調整百分率絕對值加總」作為「價格形成因素之相近程度」的衡量：

| 件數 | 絕對值加總範例 | 相近程度 | 權重 |
|---|---|---|---|
| 3 件 | 7% / 10% / 15% | 較高 / 普通 / 較低 | 50% / 30% / 20% |
| 2 件 | 7% / 10% | 較高 / 普通 | 70% / 30% |
| 1 件 | — | 普通 | 100% |

> 絕對值加總**愈大 → 權重愈小**。惟須另配合蒐集資料可信度綜合決定。

### 5.2 單一案件填寫三張核心表的細部順序

這是 AI 要複製的核心流程：

```
【Step 1】讀表3 — 建立每個地價區段的事實檔
  對每個區段（P001-00, P002-00, ...）擷取：
    - 使用分區、建蔽率、容積率、禁限建
    - 主要道路寬度、區段內道路平均寬度
    - 各設施：本區段內 → 距離 0；本區段外 → 讀 M 值
    - 自然條件、土地改良勾選項數
  ※ 表3 空白/未勘查之細項 → 表5 該列不評等（範本即如此）

【Step 2】查評價基準明細表（區域因素）— 事實轉等級
  依「案件行政區 + 目標區段用地別」載入正確的基準明細表
  對每個細項，用備註欄級距定義判定 → 優劣等級（第N級/共M級）
  ※ 嫌惡設施類方向相反（越遠越優）
  → 回填表3 左側等級碼，並作為表5「優劣等級」欄

【Step 3】填表5 — 等級轉修正百分比
  比準地欄：只填優劣等級
  各比較標的欄：填優劣等級 + 查方陣得修正百分比
  逐主要項目算「百分比小計」
  加總 → 影響地價區域因素總修正數 =(1)+...+(8)
  ※ 比較標的與比準地同區段 → 全部 0.00

【Step 4】填表4 個別因素 — 讀表7 + 查個別因素基準表
  比準地與各比較標的逐項（7~25）填條件值
  差異率 = 查個別因素方陣（比準地等級 vs 比較標的等級）
  免修正項填「-」，應修正無差異填 0
  合計 = Σ 差異率

【Step 5】表4 價格試算
  調整至估價基準日單價 = 土地正常單價 × (1 + 交易日期調整%)
  區域因素調整% ← 抄自表5 總修正數（必須一致！）
  試算價格 = 調整後單價 × (1 + 區域因素% + 個別因素合計%)
  調整百分率絕對值加總 = |交易日期%| + |區域因素%| + Σ|個別因素各項%|
  → 決定相近程度與權重
  比準地比較價格 = Σ(試算價格 × 權重)，四捨五入至個位數

【Step 6】表14 → 表6（下游）
  比準地地價 = 比較價格×權重 + 收益價格×權重，依尾數規則進位
  宗地市價試算 = 比準地地價 × (1 + 宗地個別因素總調整率)
```

## 7. 計算規則與數值慣例

### 7.1 修正率的符號方向（最易出錯）

**表4／表5（比較法）**：把**比較標的的價格調整成比準地**
```
試算價格 = 比較標的單價 × (1 + 調整率)
```
→ 比較標的條件**較差**時，調整率為**正**（要往上調才等於比準地）。

**表6（宗地市價估計）**：把**比準地地價調整成各宗地**
```
宗地市價試算 = 比準地地價 × (1 + 總調整率)
```
→ 宗地條件**較優**時，調整率為**正**。
（Excel 表6 實證：比準地面積 952㎡、某宗地 4456㎡ → 差異率 **+0.04**）

> ⚠️ **兩張表方向相反**。這是審查最常見的錯誤來源之一，系統務必分別處理。
> 通用安全表述：查表時 `修正率 = (較差方向之等級差) × 步長`，正負由「誰是基準」決定。

### 7.2 尾數規則（查估辦法第21條，手冊 參、六(六)）

適用於**比準地地價**與**宗地市價**，以每平方公尺為計價單位，**無條件進位**：

| 單價區間（元/㎡） | 計算至 | 進位方式 |
|---|---|---|
| ≤ 100 | 個位數 | 未達個位數無條件進位 |
| 100 < x ≤ 1,000 | 十位數 | 未達十位數無條件進位 |
| 1,000 < x ≤ 100,000 | 百位數 | 未達百位數無條件進位 |
| > 100,000 | 千位數 | 未達千位數無條件進位 |

Excel 實作（表6/表14 實際公式）：
```excel
=IF(x>100000, ROUNDUP(x,-3),
  IF(x>1000,  ROUNDUP(x,-2),
   IF(x>100,  ROUNDUP(x,-1),
              ROUNDUP(x,0))))
```

**例外**：依第27條市價變動幅度調整後之宗地市價單價，**無條件進位至個位數**即可
（因先前已經過比準地、宗地兩次進位，再依上表進位會造成重複進位）。

**其他尾數規定**
- 表4 比準地比較價格：**四捨五入**至個位數（手冊 六(十二)）
- 公保地跨2個以上區段之宗地單位地價：無條件進位至個位數

### 7.3 浮點精度注意

查估書表範本實證：
```
土地正常單價            184,763
交易日期調整 2.00%  →  184,763 × 1.02 = 188,458.26   （表上顯示 188,459）
個別因素合計 13.00% →  188,458.26 × 1.13 = 212,957.83 → 212,958  ✓ 表上值
                   但 188,459   × 1.13 = 212,958.67 → 212,959  ✗
```
→ **試算採全精度連乘，表上顯示值為進位後結果**。
AI 核算時應允許 **±1 元的容差**，否則會產生大量偽陽性。

### 7.4 表14 比準地地價

```
比準地地價 = ROUNDUP分級( 比較價格 × 權重比較 + 收益價格 × 權重收益 )
```
無收益價格時該欄填「-」，權重 0，僅採比較價格。

## 9. AI 系統實作要點

### 9.1 必須動態載入，不可寫死
- 基準明細表以 **(行政區, 用地別)** 為 key。樹林住宅 ≠ 金山商業。
- 表5 主要項目分組亦隨用地別改變（住宅有土地改良、商業有工商活動）。
- 手冊 六(八)4 允許縣市加註彈性條款：情況特殊者得於備註欄敘明理由後**酌予調整**修正百分比，惟仍須在內政部「影響地價個別因素評價基準表」規定之**最大影響範圍內**。
  → 系統對超出查表值者不應直接判錯，而應標記為「須確認備註理由」。

### 9.2 資料擷取的難點
- 表3 為**複雜合併儲存格版面**，PDF 文字抽取後欄位錯位嚴重，需版面感知解析（座標分群）。
- 設施欄位需同時擷取三元素：**名稱 / 區段內或外 / 距離 M**。
- 優劣等級以 `[N] [M]` 雙數字編碼藏在左側窄欄。

### 9.3 應優先實作的檢查（依投資報酬率排序）
1. **R4 表5總修正數 → 表4 區域因素調整百分率**（單一數值比對，最高頻錯誤）
2. **R2/R6 修正率查表核算**（純計算，可 100% 自動化）
3. **R1 表3 ↔ 表5 等級一致性**（逐列比對）
4. **表5 各項小計與總修正數加總**（算術核對）
5. **R7 權重邏輯**（絕對值加總遞增 → 權重遞減）
6. **R13 尾數規則**（分級 ROUNDUP）
7. **R8 表7 ↔ 表4/表6 條件值一致性**

### 9.4 已知待確認事項
- `題目.pdf` 表5-1 末列有「**修正差異數**」一欄，而查估書表範本之表5-2 無此列。推測為比較標的與比準地總修正數之差，**建議向承辦單位確認定義**後再實作。
- `題目.pdf` 表5-1 備註欄註明：「使用分區、建蔽率、容積率修正**併同於比較法調查估價表宗地個別因素考量調整修正**」
  → 本案這 3 項**不在表5 重複修正**，與手冊 六(九)「避免重複修正」一致。系統須支援此種案件層級的例外宣告。
- 區域因素方陣的列/行標示為「目標區段 / 基準區段」，與個別因素的「宗地(比準地) / 比準地(比較標的)」用語不同。因方陣為反對稱，實作上建議統一採**符號約定**（比較標的較差 → 正值）而非死記列行，可避免方向錯誤。
