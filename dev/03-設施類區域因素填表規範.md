## 0. 先直接回答三個問題

### Q1：手冊有沒有規定「區段外的設施，多遠才需要記錄到表格」？

**沒有固定半徑。** 手冊對這五類設施的用語一律是「填寫該地價區段**鄰近**⋯⋯之名稱」，
再要求「按本區段中心點至該設施之**距離（公尺數）**填寫」，全篇未出現任何公尺門檻。

手冊真正的規定寫在 伍、一、(二)8(1)（頁 24），原文：

> 各項設施對勘估標的價格之最大之影響設施或距離**因地制宜**，需用土地人於填寫清冊前
> 應先洽詢預定徵收土地所在地地政事務所，了解其「影響地價個別因素評價基準明細表」
> **訂定之各項設施或距離之調整級距**，再填寫對地價有影響之設施及其距各宗地之距離。
> 至於是否對地價造成影響，則由**查估人員判斷**。

亦即：**門檻不在手冊，而在該行政區、該用地別的《評價基準明細表》級距裡。**
這條寫在宗地個別因素清冊（表7）章節，但表3 的區域因素採同一套邏輯
（表5 填表注意事項 伍、五(六)1 同樣說「係以掌握區段間設施之**相對距離關係**為重點」）。

### Q2：那實務上的門檻是多少？

**有效記錄半徑 = 該細項級距表最外側的那道門檻。** 超過之後與「無」同級，再遠也不影響等級。
樹林區普通住宅用地的完整數字見 §3.2，摘要：

| 類型 | 有效半徑（樹林住宅） |
|---|---|
| 學校、市場、公園、停車場地 | **1,000 m** |
| 大型車站、觀光遊憩設施、服務性設施 | **2,000 m** |
| 站牌 | **800 m** |
| 交流道 | **4,000 m** |
| 電業／殯葬／廢棄物處理設施、環境污染 | **2,000 m** |

### Q3：表3 五大類要怎麼填進表5？

不是逐欄對應，是 **N:1 聚合 + 用地別篩選 + 查表判級 + 等級差計算**，四道手續：

```
表3 子欄位（多筆：名稱＋區段內/外＋距離）
   │  ① 用地別篩選：該用地別之表5 有此細項才需判級（§4.7）
   │  ② N:1 聚合：同一細項多個設施 → 取最近者（§5 D3）
   │  ③ 查表判級：距離／區段內／無 → 對照基準明細表級距 → 優劣等級（§5）
   ↓
表5 優劣等級欄（比準地 + 各比較標的）
   │  ④ 等級差 × 步長 → 修正百分比（§6）
   ↓
表5 修正百分比 → 百分比小計 → 總修正數 → 表4 區域因素調整百分率
```

## 1. 三份文件的分工

| 文件 | 記什麼 | 誰填 | 本文關切 |
|---|---|---|---|
| **表3 地價區段勘查表** | **事實**：設施名稱、在區段內或外、距離公尺數 | 查估單位實地勘查 | 輸入 |
| **評價基準明細表（區域因素）** | **級距**：多少公尺算優、算劣；**矩陣**：等級差對應幾 % | 直轄市／縣市政府訂定 | 判定規則 |
| **表5 影響地價區域因素分析明細表** | **等級＋修正率**：各區段優劣等級、比較標的修正百分比 | 查估單位 | 輸出 |

三者的關係是「事實 → 規則 → 結論」。**審查重點 vi 要求表5 的優劣等級必須與表3 所載內容一致**，
所以表5 不能有表3 沒有的資訊 —— 表3 空白，表5 就不得填。

> **表3 是五種用地別共用的通用表**，欄位數多於任何一張表5。
> 例如金山區商業用地的表3，「學校」四個子欄全部留白且左側無等級碼 ——
> 因為表5-2（商業用地）根本沒有「接近學校之程度」這個細項。這是**正確的留白**，不是漏填。

## 2. 手冊對設施登載的七條明文規範

### S1｜三態登載格式

手冊對這五大類的每一個設施欄位，都重複同一句話（伍、二(三)3~5、(六)1~6、(七)1~3、(八)、(九)1~4）：

> 填寫該地價區段鄰近⋯⋯之名稱，如該設施係位處**本區段內**者，應於本區段內前方之○內打ˇ或劃記；
> 如該設施係位處**本區段外**者，應於本區段外前方之○內打ˇ或劃記，
> 並按**本區段中心點至該設施之距離（公尺數）**填寫。

故每個設施欄位恰有三種合法狀態，缺一不可：

| 狀態 | 表3 填法 | 判級輸入 |
|---|---|---|
| **區段內有** | `名稱：金山區第一零售傳統市場　●本區段內　○本區段外(距 　M)` | `in_segment = true` |
| **區段外有** | `名稱：金山變電所　○本區段內　●本區段外(距 700 M)` | `distance_m = 700` |
| **無** | `名稱：無　○本區段內　○本區段外(距 　M)` | `is_none = true` |

> ⚠️ **「名稱：無」與「整欄空白」在法律意義上完全不同。**
> 前者是勘查後認定「此範圍內無此設施」，可據以判級（多數基準表明列「⋯⋯以上**或無**」）；
> 後者是**未勘查**，依審查重點 iii「各用地別應評價之細項因素是否皆已填載」應退補。
> 金山範例的處理方式正確：無高鐵站、無火車站、無捷運站、無交流道、無殯儀館、無火葬場、
> 無污水處理場、無垃圾場、無焚化爐、五項污染皆「無」—— 逐欄寫「無」，不留白。

### S2｜量測基準點：區段中心點

表3（區域因素）一律自**本區段中心點**起算；表7 宗地個別因素清冊（個別因素）則自**該宗地中心點**起算
（伍、一(二)6：「以該宗地中心點最接近之學校⋯⋯之距離」）。

> 同一設施在表3 與表7 會有**不同的公尺數**，這不是矛盾。審查時不得互相比對數值。

### S3｜沒有固定半徑，門檻來自基準明細表

見 §0 Q1。實作上的推論：

- 記錄與否的判斷權在查估人員（「是否對地價造成影響，則由查估人員判斷」）；
- 但**只要該細項在該用地別的表5 有對應列，表3 就必須有結論**——「有且距離 N 公尺」或「無」二者之一；
- 距離超過最外側門檻時，仍**建議據實填寫公尺數**而非填「無」，理由：
  審查者可據以複核「確實已勘查且確實在門檻外」，填「無」則無從分辨是勘查結果還是漏填。
  兩者判級結果相同（§3.4），故據實填寫零成本。

### S4｜路線距離與直線距離

伍、一、(二)8(3)：

> 量測標準建議以各細項是否因**通達**該地點而影響地價，決定採路線距離或直線距離。
> 例如學校、市場需通達，採**路線距離**為宜；嫌惡設施如焚化爐來自空氣污染等之影響，
> 則可採**直線距離**。惟無論採路線或直線量測距離，**每一案各個細項之量測標準須一致**。

實務對應：

| 細項類型 | 建議量測 | 理由 |
|---|---|---|
| 學校、市場、公園、車站、站牌、服務性設施、停車場地、百貨公司、金融機構 | **路線距離** | 需實際通達才享有機能 |
| 電業設施、殯葬設施、廢棄物處理設施、環境污染 | **直線距離** | 影響來自空氣、噪音、視覺，不經道路傳遞 |
| 交流道 | 依基準明細表 | **樹林區明定「以各地價區段至交流道直線距離計算」** |

> 樹林區基準明細表的「接近交流道之程度」備註欄直接寫明量測方式，
> 這是基準明細表**優先於**手冊建議的例子。填表前應逐項確認備註欄的「基準」說明。

### S5｜同一細項多個設施 → 取影響最大者

伍、一、(二)8(2)：

> 同一細項有多個設施存在（如有多個學校、多個嫌惡設施⋯⋯），則以**對當地地價影響最大者**填寫。

因為所有設施類級距都是單調距離函數，「影響最大」即**距離最近**：

- 正向設施（學校、市場⋯⋯）：最近者 → 等級最優；
- 嫌惡設施（殯葬、污染⋯⋯）：最近者 → 等級最劣。

**金山範例實證**：殯葬設施四個子欄填了墓地 80m、納骨塔 750m、殯儀館無、火葬場無，
表5-2 該列填「劣（5）」—— 取最近的 80m（<500m 即劣），而非平均或取遠者。

### S6｜同案比較基準應一致

伍、一、(二)8(2)(3)：

> 同一徵收範圍之填寫基礎需一致（亦即皆以某主要學校為填寫對象）⋯⋯
> 同一徵收案各宗地之各細項比較基準（設施）**儘量統一**。

伍、五(六)1 對表5 再次強調：

> 有關「接近程度」，係以掌握**區段間設施之相對距離關係**為重點，以利對影響地價之差異程度進行適當修正。

**S5 與 S6 可能衝突**（比準地最近的是 A 國小，比較標的最近的是 B 國中）。處理原則：

1. 表3 的子欄位設計本來就允許**逐一分別填寫**（國小／國中／高中／大專各一列），故**四個都填**，不必取捨；
2. 判級時仍依 S5 取最近者（基準表級距的文義是「接近學校之程度」，不指定哪一所）；
3. 若各區段所取設施不同且結果可能引起爭議，於表5 **備註欄敘明**所採基準
   （手冊伍、五(六)3(2) 允許於備註欄敘明理由後酌予調整）。

> **審查提示**：同一案各區段若某細項的比較設施明顯不一致（例如比準地量到大學、比較標的量到國小），
> 應要求敘明理由。這是 S6 的檢核點。

### S7｜不以距離登載的欄位（例外清單）

這五大類裡，**不是**每一欄都是「名稱＋內外＋距離」。以下欄位另有填法：

| 表3 欄位 | 所屬類 | 填法 | 依據 |
|---|---|---|---|
| 主要道路 | 交通運輸 | 名稱＋寬度（M） | 伍、二(三)1 |
| 區段內道路平均寬度 | 交通運輸 | `Σ已開闢道路總寬度 ÷ Σ已開闢道路條數` | 伍、二(三)2 |
| 站牌 — 密集程度 | 交通運輸 | 非常密集／密集／不密集 三擇一 | 伍、二(三)4 |
| 接近聚落程度 | 交通運輸 | 按優劣等級劃分方式填寫 | 伍、二(三)6 |
| 接近運銷中心程度 | 交通運輸 | 按優劣等級劃分方式填寫 | 伍、二(三)7 |
| 接近消費市場程度 | 交通運輸 | 距離（公尺數） | 伍、二(三)8 |
| 區段內道路規劃及闢建程度 | 交通運輸 | 按優劣等級劃分方式填寫 | 伍、二(三)9 |
| 電力資源 | 公共建設 | 按該設施對地價**影響之程度**填載 | 伍、二(六)7 |
| 產業用水及設施 | 公共建設 | 按該設施對地價**影響之程度**填載 | 伍、二(六)8 |
| 污廢水及廢棄物處理設施 | 公共建設 | 按該設施之**「有」、「無」**填載（無距離） | 伍、二(六)9 |
| 顧客之通行量 | 工商活動 | 依勘查資料，按優劣等級劃分方式填寫 | 伍、二(九)5 |
| 店舖之毗連狀態 | 工商活動 | 依勘查資料，按優劣等級劃分方式填寫 | 伍、二(九)6 |

> **站牌是唯一的雙軌欄位**：手冊伍、二(三)4 明定「考量區域特性，同一徵收案**僅就接近或密集程度擇一比較**，以維一致性」。
> 擇哪一個由**基準明細表的級距文字**決定：樹林區寫「區段內有站牌或距離未滿200m」→ 採**接近程度**；
> 金山區寫「區段內有／未滿200m／200m以上未滿400m⋯⋯」→ 同樣採接近程度。
> 若某區基準表寫「非常密集／密集／不密集」，才改採密集程度。
> 金山範例兩欄都填了（名稱＋●本區段內，密集程度●密集），多填無害，但**判級只用接近程度**。

> **工商活動的「數量」欄**：百貨公司、金融機構、娛樂設施、大型展示中心或觀光飯店四欄另有「數量」格
> （伍、二(九)1~4：「填寫⋯⋯之**名稱及數量**」），對應表5-2 細項名稱中的「**有無、數量、接近程度**」。
> 惟金山區基準明細表的級距只用距離（「區段內有／未滿500m／⋯⋯」），**數量未進入級距**。
> 數量欄仍應據實填寫供審查參考，但不影響判級。

## 3. 「多遠要記錄」的實際答案：有效記錄半徑

### 3.1 定義

設某細項的級距為 5 級，最外一級寫成「2000m以上**或無**」。則：

- 距離 ≥ 2000 m 與「無此設施」判到**同一級**；
- 該細項的**有效記錄半徑 = 2000 m**；
- 量到 2,500 m 或 8,000 m，對表5 的等級與修正率**毫無差別**。

同理，最內一級寫成「區段內有學校者或距離未滿300m」→ **300 m 以內不必追求精度**，
50 m 與 280 m 同為「優」。

> 亦即每個細項的距離精度只在 **[最內門檻, 最外門檻]** 這個區間內有意義。

### 3.4 三個容易搞錯的邊界語意

**(a)「區段內有」有時自成一級，有時與最近距離級合併**

| | 樹林住宅「接近站牌之程度」 | 金山商業「站牌之接近程度」 |
|---|---|---|
| 1 優 | **區段內有站牌或距離未滿 200 m** | **區段內有** |
| 2 稍優 | 200 m 以上未滿 400 m | **未滿 200 m** |

在金山，「勾本區段內」與「勾本區段外、距 150 M」**差一整級（2 %）**；在樹林則同級。
→ 這正是**表3 必須勾選區段內／外核取方塊**，不能只填距離的原因。
只填「距 0 M」在金山區會判成「稍優」，錯一級。

**(b)「或無」有寫與沒寫，結果相同但推理不同**

樹林四個嫌惡類細項的最優級都寫「2000m以上**或無**」，「無」直接命中。
金山對應的四個細項只寫「3,000m以上」，未寫「或無」。處理方式：
**「無此設施」＝距離無限遠 → 落在上界開放的那一級**（即「X 以上」那級）。

金山範例實證：廢棄物處理設施三欄全填「無」，表5-2 該列填「**優（1）**」。
（`datasets/_build/threshold.py::_match_none` 即依此二段式邏輯實作。）

**(c) 正向設施的「無」是最劣，嫌惡設施的「無」是最優**

| 設施性質 | 「無」→ | 「區段內有」→ |
|---|---|---|
| 正向（學校、市場、公園、車站、站牌、交流道、停車、服務性設施、觀光遊憩、工商活動各項） | **劣（最低級）** | **優（最高級）** |
| 嫌惡（電業、殯葬、廢棄物處理、環境污染） | **優（最高級）** | **劣（最低級）** |

金山範例雙向實證：交流道「無交流道」→ 劣（5）；廢棄物處理「無」→ 優（1）。

## 5. 判級規則：表3 事實 → 優劣等級

### 5.1 六條規則

| # | 規則 | 依據 |
|---|---|---|
| **D1** | 該細項不在該用地別的基準明細表內 → **不判級、表3 該欄留白正確** | §4.7 |
| **D2** | 該細項在明細表內、但表3 該欄空白（未勾選且無名稱） → **資料不足，退補表3**，不得自行推定 | 審查重點 iii |
| **D3** | 同一細項多個子欄 → 取「對地價影響最大者」＝**最近者**；`in_segment` 視為距離 0 但**優先比對「區段內有」級距** | 手冊伍、一(二)8(2) |
| **D4** | 勾「本區段內」→ 先找級距文字含「區段內有」者；找不到再依距離 0 判級 | §3.4(a) |
| **D5** | 填「無」→ 先找級距文字含「或無」者；找不到則落在**上界開放（「X 以上」）**的那一級 | §3.4(b) |
| **D6** | 距離數值 → 逐級比對級距區間（一律「以上」含下界、「未滿」不含上界） | 基準明細表級距文義 |

### 5.2 判級流程

```
表3 某細項的所有子欄
  │
  ├─ 全部空白（無勾選、無名稱）? ──是──► D2：退補，不得判級
  │
  ├─ 任一子欄勾「本區段內」? ──是──► D4：查「區段內有」級距
  │        （多子欄中只要有一個在區段內即成立）
  │
  ├─ 有子欄填了距離? ──是──► D3 取最小值 ──► D6：比對級距區間
  │
  └─ 全部填「無」 ──────────────► D5：查「或無」級距，或上界開放級
```

| 細項類 | rank 1（優） | rank 5（劣） | `direction` |
|---|---|---|---|
| 正向設施（學校、市場、公園、車站、站牌、交流道、停車、服務性設施、觀光遊憩、工商活動） | 距離**最近** | 距離最遠或無 | `lower_is_better` |
| 嫌惡設施（電業、殯葬、廢棄物處理、環境污染） | 距離**最遠**或無 | 距離最近或區段內有 | `higher_is_better` |
| 道路寬度 | 最寬 | 最窄 | `higher_is_better` |

**修正率矩陣一律以 rank 為索引，對兩個方向完全相同**（見 §6）。
`direction` 只是描述「原始數值 → rank」的方向，不影響 rank → 修正率的計算。

## 6. 優劣等級 → 修正百分比

### 6.1 公式

```
步長 = 該細項最大修正率 ÷ (級數 − 1)
修正百分比 = (比較標的區段等級序號 − 比準地區段等級序號) × 步長
```

等價於查矩陣 `matrix[比準地rank−1][比較標的rank−1]`。矩陣為**反對稱方陣**、對角線恆為 0。

**符號約定**：比較標的條件**較差**（rank 數字較大）→ 修正率為**正**
（表4 的算式是 `試算價格 = 比較標的單價 × (1 + 調整率)`，較差者須上調才等於比準地）。

### 6.2 樹林住宅用地的設施類算例

| 細項 | 比準地 P001 | 比較標的 P002 | 步長 | 修正百分比 |
|---|---|---|---|---|
| 接近學校之程度 | 優 (1) | 普通 (3) | 2.0 | (3−1)×2.0 = **+4.00** |
| 接近站牌之程度 | 稍優 (2) | 優 (1) | 1.0 | (1−2)×1.0 = **−1.00** |
| 廢棄物處理設施 | 優 (1) | 稍劣 (4) | 3.75 | (4−1)×3.75 = **+11.25** |
| 環境污染 | 優 (1) | 普通 (3) | 5.0 | (3−1)×5.0 = **+10.00** |

（以上為公式示範，非本案實際值——本案表3 未提供設施資料，見 §8。）

### 6.3 填表規則

| 欄位 | 規則 |
|---|---|
| 比準地欄 | **只填優劣等級，不填修正百分比**（它是基準，自己對自己恆為 0） |
| 比較標的欄 | 優劣等級 + 修正百分比，兩者都填 |
| 百分比小計 | 該主要項目**各細項修正百分比之代數和**（含負值，不取絕對值） |
| 影響地價區域因素總修正數 | `= (1)+(2)+(3)+(4)+(5)+(6)+(7)+(8)` |
| 去向 | 總修正數填入**表4「區域因素調整百分率」**（審查重點 vii 要求兩者相符） |
| 備註欄 | 依手冊伍、五(六)3(2)，若因情況特殊酌予調整修正率，**須於備註欄敘明理由**，且仍不得逾內政部「影響地價區域因素評價基準表」所定最大影響範圍 |

> **任一細項缺漏，該主要項目小計即不得計算，總修正數亦不得計算。**
> 不可以「缺的當 0」帶過——那等於默認兩區段該項條件相同，是無依據的實質認定。
