### 本文使用的標記

| 信心 | 意義 |
|---|---|
| **A** | 主管機關原始名冊＋自帶座標＋高頻更新＋涵蓋完整 → 可作判級輸入與退補依據 |
| **B** | 主管機關原始名冊，但缺座標或年更 → 可作交叉核對、候選清單 |
| **C** | 涵蓋明顯不足或語意不完全吻合 → 僅提示，**不得判「無」** |
| **D** | 語意不符或粒度不足 → 不進判級流程 |
| **—** | 無對應 API（實地勘查或非 POI 類欄位） |

| 樹林區級 | 意義 |
|---|---|
| 🟢 | 查得到，清單可信且完整 |
| 🟡 | 查得到，但清單不完整或需人工確認 |
| 🔴 | 查不到 |

| 勾選「本區段內／外」 | 無區段界線；唯一例外是土壤列管的地段地號（可經地籍判定） | ⚠️ **部分**：僅在設施距中心遠小於街廓尺度時可推定，仍**無區段多邊形**，邊界附近不判 |
| 判定任何「無」 | C／D 級來源涵蓋不足；10 個子欄根本無來源 | ❌ **維持不可**：查不到一律留白標紅，`output/thirdVersion` 有 6 個子欄即如此處理 |
| 自動產生表5-1 優劣等級 | 上述三項皆為前置條件 | ✅ **已產出** 25/29 細項；(6)(7) 因覆蓋不足仍不判級（樂觀上限規則） |

### 8.3 取得地價區段圖後的立即效果

一旦拿到地政局的**地價區段界線 SHP**，下列欄位可**當天**從 🔴 升級為可自動計算：

| 升級後可自動判級 | 子欄數 | 依據 |
|---|---:|---|
| A 級 API ＋ 自帶座標 → 直接計距 | **10** | 火車站、捷運站、站牌、交流道、國小、國中、高中、大專、停車場、服務性設施(醫院/機關) |
| B 級 API ＋ 地理編碼 → 計距（需標精度） | **9** | 公園、廣場、觀光遊憩、銀行、墓地、納骨塔、焚化爐、水污染、廢棄物污染 |

> **結論：區段圖是單一最高槓桿的缺件。** 它一次解鎖 19 個子欄（占需判級欄位的 51 %），
> 而其他任何單一資料源的取得都只影響 1~2 欄。
>
> **［2026-09-13］** 這個槓桿已用 OSM 界街交點**近似**取得，19 個子欄實際解鎖。
> 但近似不等於解決：界街交點是街廓角點的平均，不是區段多邊形的形心，
> 且無法支撐「本區段內／外」核取方塊。地政局的**地價區段界線 SHP 仍是第一順位缺件**，
> 取得後可把「臨界」標記與內／外欄一併收斂。
