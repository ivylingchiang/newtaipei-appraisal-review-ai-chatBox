## 閱讀順序

想理解**規則**：01 → 03。
想理解**資料來源與其極限**：04 → 05。
想理解**這些規則變成了什麼程式**：`datasets/README.md` → `engine/README.md`。

## 為什麼保留已被推翻的結論

04、05 兩篇原本判定「沒有地價區段界線圖資 → 所有距離欄位不可算」，後來以 OSM 界街
幾何求交點解決（誤差 570~1,128 m → 25~65.5 m）。原文沒有刪除，而是就地標註，因為
**失敗路徑本身是結論的一部分**：同樣是「用開放資料定位區段」，用地址字串比對不可行、
用線段幾何求交點可行，這個差別若把過程刪掉就看不出來了。
