## 4. 表4 個別因素 13~21 的性質（同 fourthVersion）

13~21 各細項之值來自**地價區段層級**（表3 記載與開放資料推算），非宗地勘查：

- 13、14 取自表3「主要道路」之名稱與寬度，宗地若臨巷道則實際寬度較小
- 15~20 之距離為**自區段中心點起算之直線距離**，非自宗地起算，亦非路線距離
- 19 接近商圈、21 停車方便性之級距由本專案代理判定（基準明細表無距離門檻）

同一區段內各宗地因而得到相同值，**不具宗地個別性**，須以現場勘查或表7 宗地個別
因素清冊覆核後方可送件。詳見 [fourthVersion/README.md §0](../log/fourthVersion/README.md)。

## 5. PDF 排版

`engine/export_pdf.py` 直接依工作表的版面資料（欄寬、列高、合併儲存格、框線樣式、
對齊、直書、數值格式）繪製，並比照 Excel 的「調整為一頁」縮放，不需 Excel 或
LibreOffice。其他已填工作簿也可單獨轉檔：

```bash
python3 engine/export_pdf.py <xlsx> [<pdf>]
```
